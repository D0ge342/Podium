# Podium

Podium es una red social para personas que disfrutan los juegos de mesa.  
Permite registrar partidas, consultar estadísticas, participar en grupos y conservar el historial de las sesiones de juego.

**Autor:** Josué Tiburcio Cruz

## Documentación

La documentación del proyecto se encuentra en la carpeta `docs`.

Incluye:

- Visión del producto
- Guion y bitácora de entrevista
- Especificación de requisitos
- Diagrama de casos de uso
